# Phase 0 — Foundation

## Objective

This phase focuses on **Foundation**. It is implemented incrementally; each step is independently verifiable and ends with a Git checkpoint.

## Step Method

For every step we cover: what we're building, why this design, architecture impact, exact files/folders, exact commands, code, Staff Engineer reasoning, SOLID/pattern callouts, tradeoffs, verification, what not to do, and Git checkpoint.
